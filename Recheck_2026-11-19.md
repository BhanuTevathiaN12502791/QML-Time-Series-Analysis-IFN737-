# Historical full-output recheck — 19 November 2026

This record describes the complete local experiment package before source-repository publication. Raw data, fitted checkpoints, detailed score arrays, per-site caches and private course documents are excluded from Git. The committed verification JSON and result summaries preserve the audit evidence; rerunning the full numerical audit requires first reproducing the excluded outputs. Source-only regression tests now use synthetic fixtures and need no AnoLT download.

The detection results and frozen protocol are unchanged. The audit found and corrected input, resumption and portability weaknesses, and expanded verification beyond agreement between saved scores and their own metrics.

## Corrections

1. **Prevent known section/model mismatches.** `detect.py` previously accepted another AnoLT section's CSV and labelled the output with the fitted model's section. It now rejects a conflicting known section filename or an explicit `--site` assertion. Generic history filenames cannot identify their section automatically; use `--site` and supply the correct observations.
2. **Validate resumable jobs.** File existence alone previously caused a job to be skipped. New cache sidecars bind each completed site job to source/protocol hashes, fitting code, selected parameters, software versions and complete output hashes. Missing, changed or mismatched cached results raise an error. The original jobs predate these sidecars: the full local package's bindings explicitly record that they were made after this recheck, rather than implying original-run provenance.
3. **Remove a Windows import failure.** The experiment runner imported the Unix-only `resource` module even though it did not use it. That import is removed. The isolated benchmark now conditionally uses OS high-water RSS or, when unavailable, a clearly labelled 5 ms sampled-RSS approximation. The fallback was exercised on this Mac with `resource` disabled; a full Windows-device execution has not been performed.
4. **Tighten input validation.** Empty input CSVs, fractional quarter-hour timestamps, invalid chronological endpoints and normal-only fitting with no usable training rows now receive explicit errors.
5. **Clarify diagnostic timing limits.** Baseline worker score timings cover all eligible windows, while IF worker timings cover validation and test windows. These diagnostic columns are not comparable across families. The dedicated isolated IF benchmark remains the matched PCA cost comparison.

No change was made to the source dataset, trained checkpoint weights, model-scoring mathematics, site allocation, folds, tuning choices, operating thresholds or detection results.

## Stronger numerical audit

- Verified all 147 source SHA-256 digests and original Git object hashes, plus the protocol digest.
- Independently reconstructed valid trailing-window endpoints from seven timestamp differences, and checked saved target indices, timestamps, volumes and both labels against the source CSVs.
- Checked the exact site/fold/method/seed/label grid for both the primary and normal-only experiments, including individual and aggregate files.
- Checked training/validation/test counts, disjoint test periods and identical eligible targets across methods.
- Recomputed all **30,312 metric rows** with no mismatches; both annotation sets reuse each method's threshold.
- Rechecked the full development search grid, selected forest subsample size, selected neighbour count and selected primary IF representation using development validation only.
- Recomputed the macro detection summaries from seed/fold/site averages.
- Refitted **108 models**: all eight IF representations (seed 42) and four baselines, across all three folds on fixed pilot/development/final sections **0185-E, 1196-E and 0185-W**. Their validation thresholds and held-out scores match the original records within 1e-12.
- Compared both full-package checkpoints' held-out scores and thresholds directly with their recorded evaluation fold.
- Validated 294 post-audit cache bindings and ran all three resume phases successfully with zero site jobs scheduled.

All **25 regression tests in that local recheck** passed, including exhaustive threshold comparisons against scikit-learn on 100 random tied-score examples, future-data invariance, gap handling, section mismatch rejection, cache tampering and the portable RSS fallback. The previous PCA fitting test was strengthened to fit twice after modifying future data, rather than merely checking that an already-fitted object had not changed.

The isolated timing benchmark was rerun after the portability correction. Runtime measurements naturally vary between runs; detection metrics do not.

## Unchanged main results

Mean site F1 over 117 final-evaluation sections, averaging folds and forest seeds within each section first:

| Method | Inspector set 1 mean F1 |
|---|---:|
| Adapted Si-TDD-style baseline | 0.609 |
| Time-of-week MAD | 0.419 |
| Contextual IF, full windows | 0.315 |
| Contextual IF, PCA 2 | 0.298 |
| Raw IF, full windows | 0.089 |

Temporal context helps this benchmark substantially. Two-component PCA does not improve the contextual IF mean here. Its negative site-bootstrap contrast is less certain when related directions are grouped by shared ID prefix; the main report preserves that limitation.

## Scope and evidence

This historical recheck verified the complete local benchmark and runnable code. It is not an independent data replication or evidence of live crash detection, geographic independence, zero-shot transfer or quantum performance. The 108 refits audit representative sections; they are not a retraining of every fitted forest from the full experiment. All saved primary and normal-only score/metric records were checked against the source and reported metrics.
